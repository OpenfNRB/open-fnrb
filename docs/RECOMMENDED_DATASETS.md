# Recommended global datasets

OpenfNRB accepts compatible local inputs independently of provider or country. These global sources are options for selecting data, not bundled downloads or automatic scientific defaults. Check each selected product's actual spatial coverage, epoch, vegetation definition, units, missing values, uncertainty and reuse terms. Preserve the exact version, source link and file hashes. See [input requirements](INPUTS.md) for accepted formats and required evidence.

| Input | Global source | Use and qualification |
|---|---|---|
| Aboveground biomass and uncertainty | [ESA CCI Biomass](https://climate.esa.int/en/projects/biomass/data/) | Global forest AGB and per-pixel uncertainty at 100 m. Select a matching year/version pair; check biomass definition and valid coverage for all eligible vegetation. |
| Aboveground biomass and uncertainty | [CTrees Global AGB](https://registry.opendata.aws/ctrees-agb-100m-global/) | Global 100 m biomass products. Verify the selected representation's encoding and uncertainty statistic before preparing the required dry-biomass density and sampling scale. |
| Land cover | [Copernicus Global Land Cover 10 m](https://land.copernicus.eu/en/products/global-dynamic-land-cover/land-cover-2020-raster-10-m-global-annual) | Global categorical 2020 land cover. Supply explicit class eligibility rules; map classes do not themselves define harvestable resources. |
| Land cover | [ESA WorldCover](https://esa-worldcover.org/en/data-access) | Global 10 m maps for 2020 and 2021. Use the selected release's legend and validation evidence; do not assume different versions are directly interchangeable. |
| Continuous canopy cover | [UMD/Hansen Global Forest Change](https://storage.googleapis.com/earthenginepartners-hansen/GFC-2023-v1.11/download.html) | The `treecover2000` layer is percent canopy cover for 2000, for vegetation taller than 5 m. It is suitable only where that epoch/definition is justified. Annual loss layers are not updated continuous canopy cover. This option does not supply the required canopy uncertainty: obtain and justify it separately. |
| Ecological stratification | [FAO Global Ecological Zones](https://www.fao.org/4/ap861e/ap861e00.pdf) | Global ecological-zone framework. Use suitable polygon data and map identifiers explicitly to evidenced growth/capacity parameters. Zone membership does not establish a parameter value. |
| Built-up allocation support | [GHSL built-up surface](https://human-settlement.emergency.copernicus.eu/ghs_buS2023.php) | Global built-up surface products. The tool allocates households by selected categorical area, not raw continuous built-up surface. If used, derive an evidenced categorical mask and explicit rules. Supply administrative household totals separately; built-up surface is not household count. |

Growth/capacity parameters, annual woody-fuel harvest, household totals, harvesting boundaries, access restrictions and applicable confusion matrices require assessment-specific evidence. No global map substitutes for these decisions. If consulting [IPCC forest reference tables](https://www.ipcc-nggip.iges.or.jp/public/2019rf/vol4.html), mean forest stock is not automatically logistic capacity and reported annual increment is not automatically peak logistic growth.

For the AGB route, express physical stock and uncertainty in tonnes dry woody matter per hectare on matching native grids. For the canopy route, supply continuous fraction/percent cover and a justified pre-truncation normal error scale. Provider RMSE, confidence limits and standard error are not interchangeable with these inputs without justification. Decode values once using [raster encoding guidance](RASTER_ENCODING.md); preserve real zeros and mask missing values.

Global coverage does not imply complete local pixels or local ecological validity. If suitable canopy uncertainty is unavailable, obtain appropriate evidence or use an evidenced AGB route; do not generate a zero uncertainty layer merely to pass validation. No automatic downloads or provider credentials are required for the synthetic examples.
