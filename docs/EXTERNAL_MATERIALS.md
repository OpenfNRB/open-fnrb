# External software and data

Original OpenfNRB software, guides, templates and synthetic examples are licensed under GPL-3.0-or-later. Third-party libraries and datasets retain their own terms.

The package does not redistribute QGIS, Python, NumPy, SciPy, GDAL/OGR/OSR, Shapely, pyproj or openpyxl. Users supply the QGIS Python environment; environment checks record resolved dependencies. Consult the licences supplied by those projects.

No real-world GIS datasets or source-derived ecological parameter tables are bundled. The [global dataset list](RECOMMENDED_DATASETS.md) links to providers. Retain their required attribution and reuse terms when downloading or preparing inputs. Synthetic locations, raster values, harvest, parameters and classification counts are invented for demonstration and testing.
